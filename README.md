# STAIR MANCALA

三角形の盤面 × ブロックブラスト式配置 × マンカラ式配布のパズル。静的サイトのみ（バックエンド不要）。

## ルール
- 盤面は 8×8 を対角線で切った三角形。
- 下のトレイの3ピースを**指でつかんで盤面の空きへ置く**。回転なし・重力なし。3つ使い切ると補充。
- 手駒は**テトロミノのみ**（7種×全向き＝19種、種類ごとに均等）。各枠 **約10%** の確率で、
  今の盤面のどこかに置けば発動が起きる形が選ばれる（`CHAIN_PIECE_RATE`）。
- 新しい3つが配られるとき、**必ず1つ以上は置ける**。さらに **9割** は「順番と場所を選べば3つとも置ける」
  組み合わせになる（連鎖も含めて全探索で確認、`SOLVABLE_TRAY_RATE`）。
  盤面にテトロミノが1つも入らない場合だけは保証できない。
- ラインは縦と横の2種類で、**まったく同じルール**（盤面は対角線について対称）：
  - 縦N = 右から N 本目の列（N マス）。右端が縦1。斜辺側の端は**下端**
  - 横N = 下から N 本目の行（N マス）。下端が横1。斜辺側の端は**右端**
- ラインN が満杯（ちょうど N 個）になると発動：ラインごと通路へ抜け、ベルトコンベアのように流れる
  （縦は盤面の下を右へ、横は盤面の右を下へ）。斜辺側の端のブロックが右下の共通ゴールへ入り、
  残りは同じ種類の N-1 … 1 番ラインへ斜辺側の端から入る。入ったブロックは**ブロックか壁に当たる手前まで奥へ進む**
  （他のブロックは動かない）。ただし入る先のラインが**満杯より1個少ない**ときだけは、手前のブロックを奥へ詰めて
  空欄を埋める（ラインが満杯になる）。手前の端が埋まっていて入れないとき・満杯のときは、そのブロックはゴールへ流れる。
- 処理順（1本発動するごとに盤面を再判定）：
  - 同じ向きの中では**番号が小さいライン**から
  - 縦と横の両方に満杯のラインがあるときは、それぞれの最小ラインから始めた場合の**連鎖数を比べ、
    大きくなる向き**の最小ラインから（同じなら縦）
- どのピースも置けなくなったらゲームオーバー。
- ルールは置いた瞬間に最後まで確定し、アニメーションは後から再生される。再生中でも次のピースを置ける。
  連鎖が進むほど再生が指数的に速くなり（`CHAIN_SPEED_GROWTH` / `CHAIN_SPEED_MAX`）、1ターンの連鎖は
  どんなに長くても約 `TURN_PLAY_BUDGET` ms に収まる。再生中に次を置いて待ちが溜まると、さらに `BACKLOG_SPEED` 倍速。

## 演出
- 仮置き（指に付けたまま盤面に重ねる）: 消える列のブロックを持っているピースの色に塗り替えて白いふちで脈打たせ、
  その列の番号・GOAL も光る。消える場所に入った瞬間に上昇音と軽い振動、ピースの上に `CLEAR` / `⚡n CHAIN`
- 発動の直前に満杯のラインが一瞬光る「溜め」（70ms）→ 解放
- 盤面が混んだり、置けない手駒があるピンチのときは画面の縁が暖色でゆっくり脈打つ（発動で空くと消える）
- フラッシュはブロックの色を帯びた控えめな光、背景の光は色相をゆっくり一周させて、明るさや色が偏らないようにしている
- 発動: ラインが白く光り光の帯が走る・盤面が揺れる（連鎖ほど強く）・3連鎖以上で画面フラッシュ・先頭ブロックが光の尾を引く
- ゴール: 衝撃波の輪・重力で落ちる破片・得点が浮かぶ。スコアは数字がくるくる増える
- 2連鎖以上で `Good! → Great! → Excellent! → Amazing! → Unbelievable!`（段階ごとに色と和音が派手に）
- 連続発動ターンは `COMBO n`。続くほど背景が光って脈打つ
- ゲーム中にベストスコアを超えた瞬間に紙吹雪とファンファーレ

## スコア
- 置いたマス ×1、ゴールに入った1個 ×100
- 連鎖倍率（2連鎖目以降）× 連続発動ターン(COMBO)倍率。すべて `src/core/constants.js`

## 画面
- 上: ベストスコア（王冠のピル）、サウンド・一時停止ボタン。中央に現在のスコア（3桁区切り）
- 盤面は直角が下に来るよう回転した三角形。上に GOAL、左右の通路にライン番号 1〜8
- 下: 3つのトレイ枠とリスタートボタン。デバッグパネルは URL に `?debug` を付けたときだけ表示
- フォントは `src/ui/fonts/` に同梱（Nunito / M PLUS Rounded 1c、どちらも SIL OFL）。
  和文は画面で使う文字だけのサブセットなので、**新しい和文を画面に出すときはサブセットを作り直す**

## 開発
- ルールのテスト: `node test/rules.test.mjs`（DOM 不要）
- ローカル: `python3 -m http.server` で `index.html` を開く
- **デプロイ前に `node scripts/stamp.mjs`**：CSS/JS の参照に `?v=` を付け直し、スマホが古いファイルと新しいファイルを混ぜて読むのを防ぐ

```
src/core/   constants.js board.js pieces.js mancala.js score.js game.js   … ルール（DOM非依存）
src/ui/     renderer.js main.js sfx.js styles.css                         … 描画・入力・音
test/       rules.test.mjs
```
