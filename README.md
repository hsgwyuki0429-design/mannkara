# STAIR MANCALA

落下ブロックパズル × マンカラ式配布のプロトタイプ。静的サイトのみ（バックエンド不要）。

## 遊び方
1. 3つの候補から1つを**指でつかんで盤面へ運ぶ**（PCはドラッグ、または 1/2/3 + ←→ + Space）
2. **指を離すとそこへ落ちる**（回転なし・ボタンなし）
3. 着地したテトロミノは**4セルに分離**し、各セルが真下へ落ちて積まれる
4. 列N に **ちょうど N個** 積まれるとその列が発動（`height === required`。超過は発動しない）
5. 発動列は**ベルトコンベアのように流れる**：列全体が1マスずつ下がり、下のブロックから順に通路へ出て右へ流れる。先頭（一番下だったブロック）がゴールへ入り、残りが各列へ一斉に下から押し上がる
6. 発動可能列が複数あるときは**常に列番号が最小の列**から。1列発動するごとに盤面を再判定して連鎖する

盤面は8列。**右端が列1、左端が列8**。床は右が最も高い階段状で、列N に N個積むと全列が同じ高さに揃う。
通常テトリスのライン消去は存在しない（ブロックが減るのはゴールのみ）。

## 開発
- ルールのテスト: `node test/rules.test.mjs`（DOM 不要）
- ローカル: `python3 -m http.server` で `index.html` を開く
